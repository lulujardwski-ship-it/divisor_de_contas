# divisor_de_contas
Divisor de contas 
Nosso projeto auxilia no controle de gastos e lucros, facilitando o usuario a organizar com oque esta gastando do dinheiro do seu salario e assim tem melhor controle
O usuario adiciona tudo que recebe mensalmente e todos os gastos e recebe de uma forma mas simplificada onde esta gastando o dinheiro e quanto sobra.
